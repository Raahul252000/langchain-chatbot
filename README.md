#### **Project 2: RAG with Langchain**

fastapi → Build REST APIs.
uvicorn → Run the FastAPI application.
python-dotenv → Load environment variables (API keys, configuration).
python-multipart → Accept PDF uploads via HTTP.
langchain → Core framework and abstractions.
langchain-community → Community integrations, including document loaders like PyPDFLoader.
langchain-google-genai → LangChain wrappers for Gemini chat models and embeddings.
langchain-chroma → LangChain integration with Chroma vector store.
chromadb → The actual vector database where embeddings are stored.
pymupdf → The PDF parsing library used by PyPDFLoader under the hood.
